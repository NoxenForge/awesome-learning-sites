## 学习配套工具

### [UrsaKit](https://ursakit.com/)

我自己维护的在线工具站，集中提供文本、数据格式、编码转换等实用工具，适合学习编程、整理资料时随手使用。

- **适合场景**：查看 JSON 数据、处理文本、进行编码转换等学习中的小任务。
- **推荐理由**：把常用操作集中在一个入口，方便在学习和实际操作之间切换。
- **语言入口**：[English](https://ursakit.com/) · [繁體中文（香港）](https://ursakit.com/zh-hk) · [Español](https://ursakit.com/es)

## 推荐一个站点

欢迎通过 Issue 或 Pull Request 推荐。优先收录有明确用途、可以直接访问的站点；同类工具不追求数量，尽量说明各自适合的场景。

推荐时可以使用下面的格式：

```markdown
- 名称：
- 链接：
- 分类：
- 适合的学习或实践场景：
- 推荐理由或实际使用心得：
- 是否需要登录或付费（如已知）：
```

维护时会补充使用心得、修正失效链接，并删去不再适合推荐的站点。
